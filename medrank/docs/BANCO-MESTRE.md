# Banco Mestre (1000 questões)

Arquivo: `public/templates/MEDRANK_BANCO_MESTRE_2026.json`

- Nome na UI: **BANCO MESTRE**
- Código no banco: `MEDRANK_AUTORAL_2026_LOTE_BANCO_MESTRE`
- 1000 questões autorais (entra no pool da Residência Geral)

## Importar

1. Admin → **Importar lote**
2. No topo da lista: **BANCO MESTRE** → **Carregar aqui**
3. Validar → **Confirmar importação** (atualiza se já existir)
4. Se ficar em rascunho: **Publicar**
