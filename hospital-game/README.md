# Meu Rim — Plantão 🏥

Jogo educativo estilo Duolingo sobre cuidado renal em ambiente hospitalar.

## Como jogar

1. A paciente Maria chega ao hospital com queixas renais
2. Converse com a enfermeira e o paciente em sequência realista
3. Responda perguntas clínicas com tempo limitado — a paciente piora se você demorar
4. Prescreva antibióticos com medicamento **e** dose corretos (ex.: oxacilina 2g IV 6/6h)
5. Solicite exames respeitando o que o hospital oferece (sem tomografia/RM)
6. Interprete resultados e encaminhe ao nefrologista quando indicado

## Executar localmente

```bash
cd hospital-game
npm install
npm run dev
```

Abra http://localhost:5173 no navegador.

## Build para produção

```bash
npm run build
npm run preview
```

## Conteúdo educativo

Baseado em diretrizes de doença renal crônica: função renal (eGFR), proteinúria, exames (creatinina, EAS, relação albumina/creatinina), controle de pressão em diabéticos e encaminhamento ao nefrologista.

**Aviso:** finalidade educativa. Não substitui consulta médica, diagnóstico ou tratamento.
